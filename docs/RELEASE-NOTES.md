# MapleOS 0.1.0-alpha.1 · Core Alpha

Experimental Arch-based live/installation media with a Maple Hyprland desktop,
Fish terminal experience, optional AI API client and project-scoped rootless
agent launcher. This is not a stable v1.0 or a recommended daily-driver upgrade.

Live login: `maple` / `maple`. Choose unique installed credentials. No personal
accounts, provider API keys or model weights are included. The installed system
requires login, and SSH is initially disabled.

Core edition uses Hyprland + Waybar. Full Caelestia parity, NVIDIA proprietary
support, ARM, Secure Boot enrollment, a signed downstream update repository and
a polished one-click graphical installer are not claimed.

Read the accompanying BUILD-MANIFEST.json, BOOT-TESTS.json and QA.json for actual
evidence. Check SHA256SUMS; a checksum alone is not an authenticity signature.
For multipart images, download all parts and run the included reassemble.py.
Back up your data and test this alpha in a disposable VM first.
