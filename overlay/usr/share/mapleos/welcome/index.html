Bring your own intelligence

maple doctor checks your tools. maple ask --help explains explicit local or cloud requests. No account, subscription, model weights or API keys are preloaded.

The desktop works offline. Cloud inference requires your account, network and authorization.

Agents with boundaries

maple agent --help launches an agent or command in a rootless container. Default: one read-only project, no network, no host home, no forwarded keys.

Opt into edits, network and individual credentials. Sandboxing reduces risk; it does not make arbitrary code safe.
